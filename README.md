# Анализ продуктовых метрик

## Что это
Учебный проект по анализу продуктовых метрик: конверсия воронки, когортный анализ удержания, расчёт LTV. Данные- публичный датасет e-commerce (Olist Brazilian E-Commerce).

## Как запустить
```bash
pip install pandas matplotlib
python analysis.py
## Что умеет
- Считает конверсию воронки по этапам (просмотр → корзина → покупка)
- Строит когортный анализ удержания по месяцам
- Визуализирует метрики в matplotlib
   ## Пример вывода
   Конверсия воронки по данным:
   
   | Этап | Пользователи |
   | Просмотр | 1000 |
   | Корзина | 300 |
   | Покупка | 150 |
   
   Конверсия «просмотр → покупка»: **15%**
   
   Подробности — в [docs/example_output.md](docs/example_output.md).
